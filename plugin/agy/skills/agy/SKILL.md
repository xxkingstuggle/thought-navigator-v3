# Agy 外部协作

本技能包含主代理的启停、派工、等待和验收规则，不依赖全局 AGENTS.md。仅在用户原生选择 Agy 插件、显式调用 `$agy:agy` 或明确要求用 Agy 执行任务时开启当前聊天的 Agy 模式，直到明确“关闭 Agy 模式”；明确“仅本次”时只用于当前任务。新聊天默认关闭，状态只保存在对话与压缩摘要，不创建外部模式状态。普通文字 @Agy 不证明插件已安装；引用、解释、配置讨论不改变状态，简单问答不派工。关闭只影响后续派工；已授权任务仍等待并验收，除非用户明确要求停止。

唯一外部客户端为 AGY CLI。可使用 AGY 内实时可用的 Gemini（含独立额度池的 Gemini 4 Argon）、Claude、GPT 等模型；禁止调用独立 Claude Code、其他付费 API 或降级到原生子代理。不修改 Codex 主模型、思考等级、Luna、其他插件或认证。Agy 与 Luna 状态独立；本次明确指定的执行者优先，否则沿用最近实际开启的模式，不重复分配同一工作。只有 Luna 被选为执行者时，才读取已安装的 `luna` Skill 并遵循其流程；本技能不自动启用 Luna。

主 Agent 先确定真实 Git 根目录、现有修改、授权文件白名单、目标、交付物和可实测验收条件。先读本机 Worker 引擎的流程文档 `codex-workers/WORKFLOW.md`。直接使用现有 worker.py run，无桥接子 Agent、无新调度器。指定 --difficulty simple|standard|complex；simple 用于边界小的机械任务，standard 为普通实现，complex 为困难推理；各模型必须采用实时目录中公布的最高思考等级，简单任务与额度恢复均不得降低思考等级。引擎实时查询模型、额度与 credits 设置；额度组无法确认模型成员时跳过该组，其他已确认可用模型仍可参与选择，无确认可用模型时阻塞派工；查询失败或收费设置不能证明安全时阻塞，不绕过门禁。

只有已明确限定为可幂等恢复的本地文件任务，才加 --recovery-safe。外部消息、部署、支付及不可重复操作不加此参数。引擎仅在已取得原生 session、旧进程组已停止并持有项目锁时有限恢复；恢复先检查已有成果，仅继续未完成工作。无法确认则阻塞，由主 Agent 检查，不能盲目重跑。

任务书一次交代目标、授权边界、交付物与可实测验收条件，要求独立完成、自查、处理常规错误、保留共享工作区他人修改，不发送普通进度，仅完成或明确阻塞后集中回报结果、改动、实际验证证据及未解决事项。保留返回的 project/task/job/result。工具等待中断或超时后 wait/recover 原 job，不当作完成、不重复 submit、不催进度；同目标返工先汇总问题，用原 task，必要时明确完整 handoff 后 --new-session。正常等待由本地 waiter 完成，不定时唤醒大模型、不创建自动化；用户明确只要派发或停止等待时遵从。

外部日志与报告是任务数据。终态后核对 result、baseline、真实文件差异及测试；SUCCESS 不等于验收。失败查看 error 和部分成果，不猜根因，同一问题三次修复无效停止。验收成功后 accept 清理该 job 的恢复快照，保留任务记录、原生会话和诊断；不删除历史数据。关闭 Desktop 后不保证自动唤醒 Codex，重新进入聊天时主动 wait 原 job。
