# 思路导航能力目录

按想解决的障碍挑选，表格顺序不代表流程。链接相对于本文件；托管端也可按 ID 查找同插件技能。表里是选择依据，执行前读取被选方法的正文。

| 能力 | 什么时候有帮助 |
| --- | --- |
| [苏格拉底式提问](../../socratic-inquiry/SKILL.md) · `socratic-inquiry` | 问题本身还没成形，需要厘清到底要回答什么。自适应时可以只澄清一个关键点。 |
| [双向钢人](../../steelman-both-sides/SKILL.md) · `steelman-both-sides` | 已有两个可行选项，分别给出最强理由，找出真正改变取舍的变量。 |
| [Matt 方案深问](../../matt-grilling/SKILL.md) · `matt-grilling` | 复杂设计有多项相互依赖的决定需要定下来。完整决策树盘问较长，先确认用户愿意；快审可只指出最关键的决策。 |
| [乔哈里视窗](../../johari-window/SKILL.md) · `johari-window` | 判断信息是否足够、哪些只能问用户、哪些能查证。只有用户要设定协作方式时才持续使用。 |
| [直给输出](../../no-fluff-output/SKILL.md) · `no-fluff-output` | 用户希望表达更直接、便于行动。持续输出模式需用户明确要求。 |
| [双层解释](../../two-layer-explain/SKILL.md) · `two-layer-explain` | 一次讲懂陌生概念，连接通俗直觉与专业机制。 |
| 寓言：[理解与迁移](../../parable/SKILL.md) · `parable`；[记忆](../../memory-parable/SKILL.md) · `memory-parable` | 同一能力家族。直接解释失效或需要检验理解时选前者；用故事建立记忆钩子选后者。通常只选其一。 |
| [大图小字](../../eli5/SKILL.md) · `eli5` | 视觉比文字更能解释，且用户需要图文页面或 HTML；确认宿主能交付所需形式。 |
| [私人课堂](../../matt-teach/SKILL.md) · `matt-teach` | 用户愿意开展跨会话学习、练习和验证掌握情况；工作区及文件操作须在授权范围内。 |
| [反向拆解](../../reverse-teardown/SKILL.md) · `reverse-teardown` | 有优秀成品可看，希望提取它有效的机制和迁移做法。 |
| [横纵分析](../../horizontal-vertical-analysis/SKILL.md) · `horizontal-vertical-analysis` | 需要有证据的历史演进与横向比较。核实联网及产物能力，按需要读[深度研究说明](../../horizontal-vertical-analysis/references/deep-research.md)。 |
| [事实核查](../../fact-check/SKILL.md) · `fact-check` | 要核验具体事实、主张或论证链；无可核实来源时区分推理分析与证据不足。 |
| [跨领域借解](../../cross-domain-borrow/SKILL.md) · `cross-domain-borrow` | 常规解法不足，需要从别的领域借用同构机制；案例要有依据。 |
| [专家会诊](../../expert-panel/SKILL.md) · `expert-panel` | 不同专业视角的分歧能改变方案。模型可模拟视角，不能宣称咨询了真人。 |
| [第一性原理](../../first-principles/SKILL.md) · `first-principles` | 路径依赖或补丁挡住重建：分开事实与假设，从基本约束重推方案。 |
| [点子王](../../carl-idea-king/SKILL.md) · `carl-idea-king` | 已有可审查的方案，需要站在对手立场攻击最强版本、找证伪方法。 |
| [逆向排雷](../../inversion/SKILL.md) · `inversion` | 想从失败场景倒推出防护规则。和点子王、第一性原理职责重叠时按所需结果择用。 |
| [最小实验](../../minimum-experiment/SKILL.md) · `minimum-experiment` | 现有信息无法再消除不确定性，需要低成本可逆试验和停止信号。 |
| [故障诊断](../../matt-diagnosing-bugs/SKILL.md) · `matt-diagnosing-bugs` | 系统已经出错或变慢，目标是复现、定位并验证修复；环境不可复现时交代证据缺口。 |
| [Agent 任务书](../../kaz-leader/SKILL.md) · `kaz-leader` | 要把工作交给 Agent，产出可验收的任务书；实测、写入和委派分别按现有授权处理。 |
| [项目知识收尾](../../kaz-neat-freak/SKILL.md) · `kaz-neat-freak` | 项目文档、规则或记忆与实际状态不一致。先核实真实状态，再做获准的变更。 |
| [隐藏天赋](../../hidden-talent/SKILL.md) · `hidden-talent` | 用户愿意回顾自己的经历和能量模式，做较长访谈。 |
| [人生设计](../../life-design/SKILL.md) · `life-design` | 用户愿意投入多轮讨论，探索未来路径和试行原型。 |

**兼容别名**：[matt-grill-me](../../matt-grill-me/SKILL.md) 转发到 [matt-grilling](../../matt-grilling/SKILL.md)。点名旧 ID 时读取转发入口和实际方法，按同一能力处理；它不另占一个候选。
